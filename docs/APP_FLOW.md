# 应用流程与导航

## 1. 页面结构总览

```
侧边栏导航
├── 首页/概览          /dashboard
├── 数据管理            /data
├── 任务配置与求解      /solve
├── 决策看板            /result
├── 算法对比分析        /compare
└── 历史记录            /history       (Nice-to-have)
```

**路由表：**

| 路由路径 | 组件名 | 是否需要登录 | 说明 |
|---------|--------|-------------|------|
| `/login` | LoginView | 否 | 登录页，全屏布局 |
| `/dashboard` | DashboardView | 是 | 系统首页，项目简介与快速入口 |
| `/data` | DataManageView | 是 | 数据加载与预览 |
| `/solve` | SolveView | 是 | 参数配置 + 一键求解 + SSE 日志 |
| `/result` | ResultView | 是 | 决策看板（KPI + 地图 + 图表 + 表格） |
| `/compare` | CompareView | 是 | 多算法性能对比 |
| `/history` | HistoryView | 是 | 历史方案列表（Nice-to-have） |

## 2. 用户流程图

```
[登录页]
   │ 输入账号密码
   ▼
[首页/概览]
   │ 点击"开始新任务"或侧边栏导航
   ▼
[数据管理页]
   │ 选择数据源：Solomon 算例 / 首尔数据集
   │ 预览客户点分布（地图 + 表格）
   ▼
[任务配置与求解页]
   │ 1. 选择算法（改进ACO / 标准ACO / GA / SA）
   │ 2. 设置决策偏好（省钱 / 抢时间 / 均衡 / 自定义λ）
   │ 3. 设置车辆载重 Q
   │ 4. （可选）展开高级参数面板
   │ 5. （仿真模式）设置应急等级比例
   │ 6. 点击【启动智能排线】
   │ 7. SSE 日志实时滚动显示迭代进度
   ▼
[决策看板页]
   │ 查看：KPI 卡片 + 路线地图 + 收敛曲线 + Pareto 图 + 调度表
   │ （可选）导出 Excel
   ▼
[算法对比分析页]
   │ 选择多个算法 + 同一数据集，查看对比图表
   ▼
[历史记录页]（Nice-to-have）
   │ 查看过往方案
```

## 3. 各页面详细描述

### 3.1 登录页 `/login`

| 元素 | 说明 |
|------|------|
| 布局 | 全屏居中卡片，不显示侧边栏 |
| 账号输入框 | 固定管理员账号 |
| 密码输入框 | 固定密码 |
| 登录按钮 | 校验通过后跳转 `/dashboard`，返回 JWT Token |
| 错误提示 | 账号或密码错误时 Element Plus Message 提示 |

### 3.2 首页/概览 `/dashboard`

| 元素 | 说明 |
|------|------|
| 项目简介卡片 | MOURO 系统名称、版本、简要说明 |
| 快速入口 | 三个按钮：加载数据、开始求解、查看对比 |
| 系统状态 | 当前已加载的数据集名称、上次运行时间 |

### 3.3 数据管理页 `/data`

| 元素 | 说明 |
|------|------|
| 数据源选择 | Radio 切换：基准模式（Solomon）/ 仿真模式（首尔） |
| Solomon 下拉框 | 选项：C101、C201、R101、R201、RC101、RC201 |
| 首尔数据集选择 | 下拉选择具体实例文件 |
| 应急等级比例设置 | 仅仿真模式可见，三个数字输入框（医疗%/生鲜%/普通%），总和=100 |
| 数据预览地图 | Leaflet 地图展示客户点分布，depot 用特殊图标标注 |
| 数据预览表格 | Element Plus Table 展示客户列表（ID、坐标、需求量、时间窗、应急等级） |
| 加载按钮 | 点击后请求后端解析数据，成功后地图和表格刷新 |

### 3.4 任务配置与求解页 `/solve`

| 元素 | 说明 |
|------|------|
| 前置检查 | 未加载数据时禁用求解按钮，提示先去数据管理页 |
| 算法选择 | Radio Group：改进ACO / 标准ACO / GA / SA |
| 决策偏好 | 三个预设按钮 + 自定义模式（三个 Slider，总和锁定为1） |
| 车辆载重 Q | InputNumber，默认 1000，范围 [100, 5000] |
| 高级参数面板 | Collapse 折叠面板，根据所选算法动态显示对应参数（见下方三张表） |
| 启动按钮 | 【启动智能排线】，点击后进入 Loading 状态 |
| SSE 日志框 | 黑底绿字终端风格，自动滚动，显示迭代进度 |
| 完成提示 | 算法结束后弹出 Success 通知，自动跳转 `/result` |

**高级参数面板字段：**

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 蚂蚁数量 | 与客户数相同 | [10, 200] | 每轮迭代蚂蚁数 |
| 最大迭代次数 G_max | 200 | [50, 500] | 终止条件上限 |
| 早停耐心值 patience | 50 | [10, 100] | 连续无改善代数 |
| α（成本信息素重要度） | 1.0 | [0.1, 5.0] | — |
| β（成本启发式重要度） | 2.0 | [0.1, 5.0] | — |
| γ（时间信息素重要度） | 1.0 | [0.1, 5.0] | — |
| δ（时间启发式重要度） | 2.0 | [0.1, 5.0] | — |
| ρ_cost | 0.1 | [0.01, 0.5] | 成本信息素挥发系数 |
| ρ_time | 0.1 | [0.01, 0.5] | 时间信息素挥发系数 |

**GA 参数（选择遗传算法时显示）：**

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 种群大小 | 100 | [20, 300] | 每代个体数 |
| 最大迭代次数 | 200 | [50, 500] | 终止条件上限 |
| 早停耐心值 | 50 | [10, 100] | 连续无改善代数 |
| 交叉概率 | 0.8 | [0.5, 1.0] | 顺序交叉概率 |
| 变异概率 | 0.1 | [0.01, 0.3] | 变异概率 |

**SA 参数（选择模拟退火时显示）：**

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 初始温度 | 1000 | [100, 5000] | 起始温度 |
| 降温系数 | 0.995 | [0.9, 0.999] | 每轮温度乘以此系数 |
| 终止温度 | 0.001 | [1e-4, 1.0] | 低于此温度停止 |
| 最大迭代次数 | 200 | [50, 500] | 终止条件上限 |
| 早停耐心值 | 50 | [10, 100] | 连续无改善代数 |

### 3.5 决策看板页 `/result`

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶栏 | KPI 卡片 ×4 | 总成本(F1)、加权时间(F2')、惩罚金额(F3)、车辆使用数 |
| 顶栏 | 预检告警 | 若有不可达客户，显示红色 Alert 组件 |
| 主区域 | 路线地图 | Leaflet 地图，不同车辆用不同颜色路线，depot 特殊图标 |
| 主区域 | 地图交互 | 悬浮客户点弹出：编号、应急等级、预计到达、时间窗状态 |
| 右侧/下方 | 收敛曲线 | ECharts 折线图，X轴=迭代次数，Y轴=Z值 |
| 右侧/下方 | Pareto 散点图 | X轴=F1，Y轴=F2'，当前方案红点高亮。数据来源：从 solutions 表读取同一数据集的历史运行结果；若仅有当前一次运行则只显示单点 |
| 底部 | 调度明细表 | Element Plus Table，按车辆分组，列：车辆号/客户顺序/到达时刻/卸货重量/惩罚 |
| 底部 | 导出按钮 | 导出 Excel（Nice-to-have） |

### 3.6 算法对比分析页 `/compare`

| 元素 | 说明 |
|------|------|
| 数据集选择 | 下拉框选择当前已加载的数据集 |
| 算法多选 | Checkbox Group：改进ACO / 标准ACO / GA / SA（至少选2个） |
| λ 配置 | 使用统一的 λ 组合进行公平对比 |
| 运行按钮 | 依次运行所选算法，每个算法运行 5 次（用于统计平均值和标准差），SSE 推送各算法进度 |
| 对比柱状图 | ECharts 分组柱状图：X轴=算法名，Y轴=F1/F2'/F3/Z（四组柱） |
| 收敛对比图 | ECharts 多折线图：不同算法的 Z 值收敛曲线叠加 |
| 性能指标表 | 表格：算法名/最优Z/平均Z/标准差/运行时间/车辆数 |
| 锚点校验表 | 三个锚点（纯成本/纯时效/纯服务）的准确率对比 |

### 3.7 历史记录页 `/history`（Nice-to-have）

| 元素 | 说明 |
|------|------|
| 方案列表 | Element Plus Table：运行时间/数据集/算法/Z值/车辆数 |
| 查看详情 | 点击某行跳转到对应的决策看板快照 |
| 删除 | 删除历史记录 |

## 4. 前后端交互流程

### 4.1 登录流程

```
前端                          后端
 │  POST /api/auth/login       │
 │  {username, password}  ───► │ 校验固定账号密码
 │                        ◄─── │ {token} 或 401
 │  存储 token 到 localStorage │
```

### 4.2 数据加载流程

```
前端                              后端
 │  POST /api/data/load            │
 │  {mode, instance,               │
 │   emergency_ratio}        ───►  │ 解析数据文件
 │                                 │ 生成缺失字段（仿真模式）
 │                                 │ 构建距离矩阵
 │                           ◄───  │ {nodes, customers, depot, matrix_info}
 │  渲染地图 + 表格                │
```

### 4.3 求解流程（SSE）

```
前端                                    后端
 │  POST /api/solve/start                │
 │  {algorithm, lambdas, Q,              │
 │   aco_params}                   ───►  │ 启动算法线程
 │                                 ◄───  │ {task_id}
 │                                       │
 │  GET /api/solve/stream/{task_id}      │
 │  EventSource 连接               ───►  │
 │                                 ◄───  │ SSE: {iteration, best_z, ...}
 │                                 ◄───  │ SSE: {iteration, best_z, ...}
 │                                 ◄───  │ SSE: {type: "done", task_id, ...}
 │  关闭 EventSource                     │
 │  GET /api/solve/result/{task_id}───►  │
 │                                 ◄───  │ {success, data: {routes, kpi, ...}}
 │  跳转 /result                         │
```

### 4.4 算法对比流程

```
前端                                    后端
 │  POST /api/compare/start              │
 │  {algorithms[], lambdas, Q}     ───►  │ 依次运行各算法
 │                                 ◄───  │ {task_id}
 │                                       │
 │  GET /api/compare/stream/{task_id}    │
 │  EventSource 连接               ───►  │
 │                                 ◄───  │ SSE: {algo: "aco", iteration, ...}
 │                                 ◄───  │ SSE: {status: "done", results: [...]}
 │  渲染对比图表                         │
```

## 5. 状态管理要点（Pinia Store）

| Store 名称 | 管理的数据 | 跨页面共享 |
|------------|-----------|-----------|
| `useAuthStore` | token、登录状态 | 是（全局路由守卫） |
| `useDataStore` | 当前数据集模式、节点列表、客户列表、距离矩阵元信息 | 是（数据页→求解页→看板页） |
| `useSolveStore` | 当前算法选择、λ配置、Q值、算法参数、求解状态、task_id | 是（求解页→看板页） |
| `useResultStore` | 求解结果（路线、KPI、收敛数据、Pareto数据） | 是（看板页、对比页） |
